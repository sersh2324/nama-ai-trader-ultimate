# NAMA AI Trader Ultimate 1.0.0

نسخة تأسيسية متكاملة مبنية على متطلبات المشروع المعتمدة:
- السوق الأمريكي والسعودي.
- المضاربة اليومية والـSwing والاستثمار طويل الأجل.
- تحليل فني + بيانات أساسية + أخبار.
- خمس استراتيجيات قابلة للاختيار أو الاختيار التلقائي.
- إشارات يدوية، وإعداد معماري للتنفيذ الآلي مستقبلاً (غير مفعل).
- إدارة مخاطر وحجم صفقة.
- اختبار تاريخي مع رسوم وانزلاق مفترضين.
- سجل محفظة وتنبيهات وقائمة مراقبة باستخدام SQLite.
- واجهة عربية على Streamlit.

## التشغيل محلياً

```bash
python -m venv .venv
# Windows:
.venv\\Scripts\\activate
# macOS/Linux:
source .venv/bin/activate

pip install -r requirements.txt
streamlit run app.py
```

## النشر على Streamlit Community Cloud
1. ارفع محتويات المجلد إلى مستودع GitHub خاص أو عام.
2. اختر `app.py` كملف رئيسي.
3. ثبّت المكتبات من `requirements.txt`.
4. لا تضع مفاتيح أو كلمات مرور في الكود.

## مزود البيانات والقيود
- يعتمد الإصدار الحالي على Yahoo Finance عبر مكتبة yfinance دون مفتاح API.
- التغطية والفواصل الزمنية والبيانات الأساسية والأخبار تختلف حسب الرمز والسوق.
- بيانات اليوم الواحد ليست بالضرورة لحظية. فواصل 1m و2m و5m و15m وغيرها لها حدود تاريخية يفرضها المزود.
- لا توجد تغطية مضمونة لكل الأسهم السعودية أو لكل الفواصل اللحظية.
- لا توجد حالياً قاعدة بيانات سحابية خارجية؛ SQLite محلية وقد لا تستمر بعد إعادة نشر Streamlit Cloud.
- تصنيف الأخبار في هذه النسخة قائم على كلمات مفتاحية، وليس نموذج ذكاء اصطناعي لغوي مدرب.
- اختيار الاستراتيجية التلقائي يختار أعلى درجة قواعدية، وليس نموذج تعلم آلي.
- VWAP المحسوب على البيانات اليومية تقريب تقريبي، ولا يعادل VWAP جلسة التداول من بيانات لحظية.

## منهجية الاختبار
- الإشارة عند إغلاق الشمعة، والدخول عند افتتاح الشمعة التالية.
- وقف الخسارة له الأولوية إذا لمس الوقف والهدف في الشمعة نفسها.
- الرسوم والانزلاق قيم افتراضية قابلة للتعديل.
- الاختبار لا يتضمن كل عوامل السوق مثل الضرائب والقيود التنظيمية وتكاليف الاقتراض.
- نتائج الاختبار التاريخي ليست ضماناً للأداء المستقبلي.

## حدود السلامة
- لا يوجد تنفيذ صفقات حقيقية في هذا الإصدار.
- لا تُدخل بيانات دخول الوسيط أو مفاتيح حساسة داخل التطبيق.
- لا تستخدم النتائج كتوصية استثمارية مستقلة.


## تحديث 1.1 — الفحص التلقائي

- فحص دفعات من 25 إلى 1000 سهم؛ استخدم بداية الدفعة للوصول لبقية الأسهم.
- مصدر الرموز الأمريكية: Nasdaq Trader، والسعودية: دليل SAHMK الخارجي غير الرسمي؛ قد تتغير إتاحتهما.
- إذا فشل اكتشاف الرموز يستخدم البرنامج قائمة احتياطية محدودة، ولا يدعي تغطية السوق كاملًا.
- بيانات الأسعار من yfinance وقد تكون ناقصة أو متأخرة؛ عدد الرموز المكتشفة لا يساوي عدد الرموز القابلة للتحليل.
- الماسح يعتمد على مؤشرات وقواعد، وليس نموذج ذكاء اصطناعي مدربًا.
- ابدأ بـ25 أو 50 رمزًا لتجنب قيود المزود.
- تخزين SQLite المحلي في Streamlit Cloud قد لا يستمر بعد إعادة التشغيل.
- لا توجد أوامر تداول حقيقية أو تنفيذ آلي.
